# 版本1.6：MMAUD真实短片段对照

开始日期：2026-10-07；分支`v1.6-mmaud`，基于已冻结`v1.5`（`06dc1bf`）。最终完成状态及结果见本文后续步骤。

用户要求：先选一段有清晰目标、雷达回波和连续真值的真实短片段，比较“仅雷达”与“雷达＋相机”；每一步保存到GitHub并说明工作，图表标注中文。

## 第0步：隔离版本与准备环境

已建立独立D盘工作目录和虚拟环境，保留1.5和2.0工作目录。固定离线数据处理依赖于`requirements-v16.lock.txt`。新环境中原有62项算法检查全部通过。

安装：`uv pip sync requirements-v16.lock.txt --python .venv/Scripts/python.exe`。设置uv缓存和临时目录到D盘。检查：`.venv/Scripts/python.exe -m unittest discover -s tests -q`。

GitHub提交：`7101d9b`，已推送。

## 第1a步：取得并审计独立真实真值

官方Mavic3独立真值bag已保存在D盘，158,950字节，SHA-256 `c8e2adfb3528ce93dd2c37fe2ccf9a3853108a26bfee04845b78695f87cb0cf3`。实际解析`absolute`与`relative`各904个样本，时间覆盖184.208秒；存在一次0.701923秒缺口。按0.30秒覆盖阈值分为两个连续区间，后续不跨缺口评价。

`/tf`只有随目标运动的Leica绝对/相对位置，不能当作雷达—相机或雷达—世界标定。位置原始bag和导出CSV留本地忽略目录，GitHub只保存来源、哈希、格式、覆盖审计和中文时序图。

运行：`.venv/Scripts/python.exe tools/audit_mmaud_truth.py`；[审计报告](../output/v16_truth_audit/report.md)。本步骤未运行算法精度评价，也未宣称三种模态已配准。

GitHub提交：`ee3231b`，已推送。

## 第2步：准备真实位置与视线融合适配

新增独立`mmaud_filter.py`：三维雷达NIS门控与最近点关联；相机输入为实际图像经明确投影模型得到的归一化视线，使用解析雅可比EKF，不引入伪深度。正式模型需镜头矫正，本次实际数据另行采用局部实验映射并披露限制。两组共用雷达初始化、100 Hz输出和所有预测分区；全部更新记录门控与选点。

核心无真值接口。原有62项及新增9项几何、初始化、公平分区、门控检查共71项全部通过。此阶段是软件检查，不是MMAUD真实精度结果。观测维度、初始化、相机视线模型及离散Q适配限制见[算法说明](v1_6_algorithm.md)。

GitHub提交：`ff54b0b`，已推送。

## 第1b步：取得完整雷达、真值与固定片段图像

已从官方公开Mavic3 ZIP精确范围提取、核验并保存：833个GT数组、2548个增强雷达数组、88张PNG和独立真值bag，共3470文件。使用约186 MB原始归档局部跨度缓存，避免下载约10.75 GB整个包。每个成员验证ZIP CRC32并记录SHA-256；离线完整复查通过，原始材料全部Git忽略、位于D盘。

雷达数组实际仅有XYZ三列，缺速度/强度；1083对相邻完整文件CRC相同，不能视为独立观测。ZIP没有标定参数、原始radar_pcl或radar_trk。图像是2560×960双鱼眼拼接。

运行：`.venv/Scripts/python.exe tools/fetch_mmaud.py --offline --import-spans`；[材料审计报告](../output/v16_data_audit/report.md)、[完整逐文件摘要](../output/v16_data_audit/manifest.json)。数据按CC BY-NC-SA 4.0非商业学术许可使用，并引用作者ICRA 2024论文。

GitHub提交：`cdd9d37`，已推送。

## 预评估选段记录

以下选择均在任何滤波误差计算前完成，依据实际图像和雷达覆盖，不按结果择优：

- 首次候选测试范围Unix秒6957–6964（前缀169284）；逐帧雷达检查发现开头没有中心目标候选，因覆盖不足放弃。
- 最终固定测试：`[1692846959.5,1692846969.0]`，9.5秒，48张图像以约5 Hz子采样；143个雷达源帧都有候选，去除相同点集后97个更新快照。没有舍去误差大的时刻。
- 校准：`[1692846908.0,1692846923.1]`和`[1692847012.0,1692847026.1]`，31张约1 Hz图像；末端加0.1秒仅包含预先选定的实际PNG时间偏差。两段都不接触测试段，覆盖约4米和19米雷达目标距离，缓解单深度几何欠约束。使用后段校准属于离线非因果处理，不宣称在线自校准。
- 所有相对秒的原点为Unix纳秒`1692846887000000000`。目标像素来自图像检查/人工辅助标注；测试真值不会进入检测、雷达选点或初始化。独立训练真值若参与标定会明确披露。

## 完成条件

1. 保存可核验的数据来源、文件哈希、真实格式、时钟和标定审计。原始数据留本地，GitHub保存获取工具、清单与分析结果。
2. 从实际图像检查目标，从实际雷达回波检查观测，按真值覆盖连续性选固定区间。不得按最终误差挑片段。
3. 明确算法适配：MMAUD径向速度不等于原法世界系vx；若采用XYZ位置观测，标为删减适配。相机必须来自图像，不能来自真值投影。
4. 同一初始雷达观测、预测时间网格、雷达输入及评价时刻运行两组，只改变相机更新。记录门控、初始化和实际有效评价范围。
5. 输出中文图表、指标、限制与可重复入口，经检查后分阶段提交推送，完成后才发布v1.6标签。

## 第3步：固定真实输入、图像审核和独立训练标定

新增固定选段、图像人工辅助标注、雷达去重/静态背景/中心ROI/最大簇提取、标定审计与准备入口。所有阈值及滤波参数在第一次测试误差计算前固定；初始化选首簇最靠近中位数的一枚实际雷达点，非合成中位数，也不靠测试真值选点。

正式官方标定尚未取得，不能把未知参数假定为已知。相机—雷达直接传感器对应的初次标定失败，保留诊断记录；最终采用31帧独立训练图像机身中心与训练Leica监督的局部虚拟针孔模型，再与176条训练雷达—Leica刚体对应组合。主重投影RMS为6.674像素，雷达坐标变换稳定性不足，全部结果按探索性条件解释，不能称完整鱼眼矫正或物理标定。详细模型及训练重采样见[标定审计](v1_6_calibration_audit.md)。

独立输入审计确认102份来源SHA、97个雷达候选集、48条图像归一化观测和50条真值转换均匹配；31/176条训练对应均在两段校准区间内。人工辅助标注48帧逐帧检查，没有用测试GT改标注。首图早于雷达初始化6.477毫秒，因此实际参与滤波的相机事件为47次。

GitHub保存工具、派生参数、像素标注/来源摘要、审核声明与输入契约，原图/NPY/bag留D盘忽略目录。固定模型SHA `be9281c8dcd3fc7bae85c1b4b884ad039e2733027921f8e32326f3d713c88a8f`；运行/恢复见[1.6运行说明](v1_6_run.md)。

## 数据适用边界

[MMAUD官网](https://ntu-aris.github.io/MMAUD/)提供地面多传感器观测无人机数据。它适合原论文框架的外部真实数据适配验证；不能据此宣称重现原论文作者实测数值，也不能验证2.0的移动自机空对空补偿。

官方论文：[MMAUD: A Comprehensive Multi-Modal Anti-UAV Dataset for Modern Miniature UAVs](https://arxiv.org/html/2402.03706v1)。原始数据按作者CC BY-NC-SA 4.0学术用途许可使用。
