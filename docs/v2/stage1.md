# 2.0第1阶段：运动自机融合原型

## 这一步做了什么

在冻结1.5之外新增 `d2d.py`，不修改旧Kalman、雷达、相机及异步算法。新模块接收测量采集时刻自机状态，并补偿安装偏移与转动产生的传感器速度。融合真实含义的雷达距离、径向速度、角度和相机二维像素；不从目标状态复制深度来增加观测。

- 状态：世界系目标 `[x,vx,y,vy,z,vz]`。
- 自机输入：位置、速度、机体系到世界系旋转、机体系角速度；可选12维协方差。
- 传感器输入：机体系杆臂和安装旋转；相机+Z光轴、雷达+X前向。
- 雷达：`[range_m, range_rate_m_s, azimuth_rad, elevation_rad]`，距离增大速度为正；可只使用前两项。
- 过程噪声：连续白加速度谱密度，单位m²/s³。
- 更新：解析目标和自机Jacobian、角度残差归一化、NIS门控、Joseph协方差。
- 可选位姿不确定度：只是一阶独立近似，尚不消除跨时刻/跨传感器误差相关。

## 如何运行

Windows双击项目根目录的 `run_d2d.cmd`；中文图表与报告在 `output/local_d2d`。命令行也可运行：

```powershell
.\.venv\Scripts\python.exe demo_d2d.py --output output/local_d2d
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

单次参考实验报告：[output/v2_step1/report.md](../../output/v2_step1/report.md)。

## 验证与限制

2026-10-07完整检查 **77项通过**：原有62项加新增15项数学检查。新增检查覆盖非零三轴旋转下解析Jacobian与有限差分、转动杆臂、运动自机/静止目标速度符号、原地零杆臂旋转、相机深度不可观方向、连续Q分割一致、门控拒绝、±π角度跨越、协方差正定性和错误输入。

受控实验为四种平台/目标组合、三个种子、五个配置，**60组合成实验**。相同观测/初始雷达/时序；首次雷达只初始化一次，目标真值不传入跟踪函数。配置和输出包括完整状态/协方差、创新、NIS/NEES诊断和中文图表。对照设计另经独立只读审核。

1.5位置接口适配基线使用旧Kalman3D，只更新实测位置模型；不伪造全局vx，不代表冻结版本完整融合流程。它无门控，相机和Doppler也未输入，Q统计含义不同，报告明确这些差异。故障消融仅诊断遗漏自机运动的后果；结果完整保留于表格和原始输出，不作为主要性能基线。

此阶段是**单目标同步数学原型**：准确合成自机相当于受控上界，还没有检测器、真实点云关联、测量时刻自机插值、异步接入、多帧确认起轨、IMM或设备驱动。新模块没有替代1.5的完整异步管线，下一步需用实际字段与真实输入适配。已有真实视频的资料下载与格式核验另行保存，不能当作这里的真实精度验证。
