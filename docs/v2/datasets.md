# 真实数据调查：区分验证范围

核验日期：2026-10-07。能找到真实数据，但尚未找到本项目原论文作者公开的两组完整飞行日志。下面的替代数据不能称为原论文实测结果的精确复现，也不能把不同数据集的雷达与图像拼成一段真实融合观测。

## 分开验收

1. **资料核验**：来源、许可、哈希、视频/标注对应、数据字段与坐标/时钟定义。此项通过只表示材料可用，不表示算法已验证。
2. **真实视觉**：在Purdue按完整视频分训练/验证/测试，不能把同一视频相邻帧随机分组造成泄漏。报告小目标召回、精度、身份切换和跟踪误差；没有检测器前不给出检测准确率。
3. **真实融合**：MMAUD按真实bag时钟及外参转换，雷达实测Doppler与图像检测独立生成观测；真值仅供评价。缺真值的区间只跟踪、不计精度；报告真值覆盖和分段结果。
4. **真正空对空融合**：需要同期的自机位姿/速度/角速度、机载雷达、相机和目标独立参考轨迹。上述地面数据或视觉数据都不足以单独证明这一项，后续仍可能需要自采。

目前数据筛选和下载核验是第一阶段；没有宣称已经完成任何公开真实数据上的三维精度验证。
