# 2.0算法路线：无人机对无人机感知

## 任务定义

自机携带毫米波雷达、相机及能够提供自身运动状态的惯性/定位系统，估计非协作目标无人机的三维相对位置、相对速度和不确定度。先研究单目标离线融合，再扩展检测、异步系统和多目标；无人机身份协作信息不是输入前提。

这里估计目标平移状态，不估计目标完整六自由度姿态。单独的IMU不提供长期无漂移世界位置，真实运行仍需自机VIO/GNSS/导航输入。相对位置可输出为 `r_body=Rwbᵀ(p目标-p自机)`；机体系表示的相对速度是 `Rwbᵀ(v目标-v自机)`，旋转机体系位置导数还需减去 `ωb×r_body`，两者不能混用。

1.5面向已经对齐全局坐标的观测。直接迁到机载环境，会把自机转动和平移误解为目标运动；雷达径向速度不是世界坐标vx；单目图像只有方位，复制状态深度产生的三维伪观测不是新的独立深度信息。两帧位移小于0.3 m/s的初始化也不适合一般运动目标。

## 第一阶段：先修正测量物理模型

保留世界坐标目标状态 `X=[px,vx,py,vy,pz,vz]`。在**测量采集时刻**输入自机位置 `pe`、速度 `ve`、姿态 `Rwb` 和机体系角速度 `ωb`。传感器在机体系的安装偏移为 `l`，安装旋转为 `Rbs`：

```text
ps = pe + Rwb l
vs = ve + Rwb (ωb × l)
Rws = Rwb Rbs
r  = ptarget - ps
ρ  = ||r||
d  = r/ρ
ρdot = dᵀ(vtarget - vs)             # 远离传感器为正
rs = Rwsᵀ r
azimuth = atan2(rs.y, rs.x)
elevation = atan2(rs.z, sqrt(rs.x²+rs.y²))
```

雷达直接更新 `[ρ,ρdot,azimuth,elevation]`，或仅 `[ρ,ρdot]`，后者仍须由相机或先验约束方向。相机使用自身传感器原点及旋转，+Z为光轴：

```text
pc = Rwcᵀ(ptarget - pcamera)
u = u0 + fu pc.x/pc.z
v = v0 + fv pc.y/pc.z
```

用这两个像素分量更新EKF，不通过复制滤波深度构造独立XYZ。摄像头在自机机体中可以不同于雷达方向、位置；示例约定机体系+X为前向，摄像头光轴经安装旋转指向+X。

第一阶段使用解析目标状态Jacobian、Joseph形式协方差、按观测维数明确指定的NIS门控。杆臂速度必须包含旋转项；只减自机平移速度不够。奇点和目标在相机后方须显式处理。

过程噪声改为连续白加速度谱密度 `q`，每轴：

```text
Q(dt) = q [[dt³/3, dt²/2], [dt²/2, dt]]
```

`q`单位为m²/s³，与1.5每步独立恒加速度的标准差不同，不能直接复用数值。该模型使无观测预测的分割/合并保持一致，适合后续非等间隔时序。

可选自机协方差通过 `R_eff=R_sensor+Jego Σego Jegoᵀ` 一阶传播。必须注明这假设自机误差与目标状态独立，**不处理**多帧自机误差相关或雷达/相机共享位姿误差造成的相关；不能仅凭增加R声称统计一致。首轮受控仿真实验使用准确自机输入，先隔离几何模型错误。

以上是面向新场景的建模修正和组合实现，不自动构成新算法或论文创新点。[TI官方输出说明](https://software-dl.ti.com/ra-processors/esd/MMWAVE-L-SDK/05_04_00_01/exports/api_guide_xwrL64xx/MOTION_AND_PRESENCE_DETECTION_DEMO.html)区分点云坐标与径向速度；[Rai等人的雷达—惯性论文](https://arxiv.org/html/2506.14294v1)给出旋转杆臂速度模型；[SNAIL-Radar标定说明](https://snail-radar-indoor.github.io/docs/calibration.html)说明外参不确定度和同步残差问题。

## 后续改进及选择依据

| 优先级 | 改进 | 为什么做 | 如何决定有效 |
|---|---|---|---|
| P0 | 真实输入适配、自机插值、原始观测重放、运动目标初始化 | 采集时刻姿态错误会产生系统偏差；运动目标不能沿用静止门槛 | 时序/坐标校验、起轨成功率、延迟与丢包消融；明确因果输出和事后轨迹 |
| P1 | IMM：匀速/加速/转弯模型 | 目标急转时CV会滞后；自机补偿不解决目标机动 | 同一观测下与CV比较速度误差、转弯峰值误差、NEES/NIS及耗时 |
| P1 | 有界的Q/R自适应与异常观测鲁棒处理 | 雷达杂波、远距像素误差、姿态质量随时变化 | 在独立验证集标定；不能通过任意放大噪声掩盖模型错误 |
| P2 | 多目标起轨、删除、视觉身份与JPDA | 同一视场内有多架无人机、鸟类或其他杂波 | 多目标召回、身份切换、误起轨率、运行时间和资源消耗 |
| P2 | 联合/Schmidt式自机误差处理 | 多传感器共享位姿误差，简单独立更新会过度自信 | 姿态扰动、时间相关误差下的统计一致性对比 |
| P3 | 真实检测器、机载驱动与有限历史实时实现 | 数学原型还不是可用的飞行设备系统 | 独立视频测试、端到端延迟、丢帧、频率、内存和功耗实测 |

## 比较与验收原则

- 先固定平台检查不退化，再覆盖自机平移/转动、非零杆臂、静止/机动目标、掉帧和异常观测。
- 不向滤波器输入目标真值位置或速度。初始化来自首个雷达观测或外部已声明的搜索先验，速度使用宽不确定度。
- 若拿1.5比较，使用其真实可支持的XYZ位置观测及显式运动坐标适配，标注为“1.5位置接口适配基线”，不能伪造global vx或将其描述为原版全流程。主要结论先来自2.0同一骨架的逐项消融。
- 合成和真实结果分开；不同数据集分开。统计所有种子和启动期，不只选最好一次。
- 输出中文图表；同时保存固定配置、机器可读指标、状态和协方差。指标至少包含位置/速度误差和拒绝观测数；后续加入NEES/NIS、真值覆盖、起轨/失轨与计算耗时。
- 第一阶段不承诺已复现作者实测精度，不承诺IMM、多目标、真实检测或实时部署已完成。
