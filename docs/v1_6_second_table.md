# 1.6补充：每秒位置、速度与方差表

按用户要求，从已冻结的1.6真实对照结果导出每隔1秒的状态表。以首雷达初始化为t=0，取t=0–9 s的10个时刻；每个时刻有Radar only和Radar+Camera两种方法，共20条记录。对应原日志时间为72.512097–81.512097 s。末尾不足1秒不额外填行。

## 列的含义

| 符号 | 含义 | 单位 |
|---|---|---|
| t / t_log | 自初始化起的秒数 / 相对日志时钟 | s |
| x, y, z | 滤波后位置 | m |
| Vx, Vy, Vz | 滤波后速度分量 | m/s |
| V | 速度模长，sqrt(Vx²+Vy²+Vz²) | m/s |
| x_ref, y_ref, z_ref | Leica位置真值经冻结坐标链、时间插值后的参考位置 | m |
| Vx_ref, Vy_ref, Vz_ref / V_ref | 真值位置差分得到的速度分量 / 模长 | m/s |
| Var(x), Var(y), Var(z) | P矩阵位置对角项P_xx、P_yy、P_zz | m² |
| Var(Vx), Var(Vy), Var(Vz) | P矩阵速度对角项P_VxVx、P_VyVy、P_VzVz | m²/s² |

数据源没有直接测量的速度真值。V_ref采用t前后各0.5秒的实际位置线性插值，再计算 `[p(t+0.5)-p(t-0.5)]/1s`。它是以t为中心的1秒窗口平均速度近似，不能视为精确瞬时测速。整个窗口内缺口不得超过0.30秒，不外推；参考速度方差未知，未编造为零。

V_ref标量是该窗口平均速度向量的模长，即净位移/1s，不是沿运动路径的平均速率。仅雷达t=0–4s的零速度来自已保存状态，未填补缺失值；更新记录显示连续选择同一初始XYZ旧回波，并不表示目标真值静止。

方差是滤波器在固定参数条件下的后验模型值，不等于实际误差平方，也没有显式传播完整标定参数的不确定性。R使用训练残差的混合噪声估计，不能把P当作实测精度保证。所有状态和方差直接取原100Hz结果中的tick 0、100、…、900，不插值滤波状态、不重新运行或修改算法。数学符号和SI单位保留英文，说明使用中文。

## 文件与重建

Excel包含Position和Velocity两张表，按位置与速度分开，保留两组方法、同一参考真值和相应方差。具体数值及完整来源见[逐秒报告](../output/v16_second_table/report.md)和[CSV](../output/v16_second_table/second_samples.csv)，CSV/JSON保留完整浮点精度。

生成逐秒数值：

```powershell
$env:PYTHONUTF8='1'
.\.venv\Scripts\python.exe tools/export_mmaud_second_table.py
```

导出器校验已发布1.6主指标、完整状态协方差文件、模型和实际GT来源摘要；真值速度只旋转，不加位置平移。解析匀速/二次轨迹和缺口/外推拒绝检查、原状态/方差逐值核对均通过。

Excel使用`tools/build_mmaud_second_table.mjs`读取派生JSON建立，V/V_ref由简单单元格公式计算。构建需要桌面提供的工作文档运行环境；日常查看Excel和Python导出CSV不需要额外安装该环境。保存前进行重算、公式错误扫描和两张表的可视检查。
