# 1.6：MMAUD 位置观测与相机视线适配

本模块独立于冻结的 1.5，不修改原来的四维 `[XYZ,world_vx]` 雷达接口。本次取得的MMAUD增强点云仅有XYZ，没有速度或强度列，因此 1.6 明确使用三维 XYZ 观测、`H=eye(6)[0,2,4]`、3×3 `radar_R`；若未来取得原始径向Doppler，也不能直接当作世界 x 速度。本版本是原法的观测删减及相机 bearing 适配，不能称为作者表 I 逐数复现。

## 输入与初始化

`RadarFrame(timestamp,points)` 包含真实雷达坐标中的米制 `(N,3)` 候选点；空帧用 `(0,3)`。`CameraFrame(timestamp,normalized_xy)` 只接收实际图像检测/标注得到的目标视线，以明确投影模型下的 `(X/Z,Y/Z)` 表示。正式标定应先做镜头去畸变；本次实际短片段使用独立训练GT监督的近轴局部针孔映射，原鱼眼图未完整矫正，必须按探索性结果解释。时间统一为日志时钟的相对秒，硬件同步尚未确证；各传感器每个记录时刻最多一帧。核心没有真值参数。

`run_comparison` 默认以所选区间首个非空雷达帧的 `points[0]` 初始化，位置协方差为 `radar_R`，速度为零、方差为 `velocity_std²`。调用者可使用 `initial_point_index` 显式选点。默认首点是可追踪的参考策略，**不保证属于目标**；调用者必须记录依据，不能用真值选点。该点只用于初始化一次，不再当作普通观测重复更新。

可选 `initial_velocity_from_two=True` 用前两非空帧的调用者选点建立位置与有限差分速度；`initial_second_point_index` 可明确第二点。调用者应保证两点是同一目标的观测，不能用真值速度。此时位置/速度协方差和交叉项由两个独立、相同 `radar_R` 的位置噪声传播，属于明确假设。

本适配没有采用原论文两最强点 `<0.3 m/s` 初始化门槛；无强度时无法选择最强点，动态飞行也可能无法满足该门槛。此处变更必须作为适配条件记录。

## 雷达关联与相机更新

雷达所有原始 XYZ 候选先按三维 NIS 门控，再选择门内距预测 XYZ 最近的点进行一次线性更新。没有强度前，不实现或冒称 Strongest、强度 Weighted 或完整五方法对比。默认门槛为三维 NIS 11.344866730144373，相机二维 NIS 9.210340371976184，均为显式实验设定。每次更新记录测量时刻、NIS、是否通过门控、候选数量与选点索引。

`Calib(rotation,translation,noise_norm)` 使用 **`p_radar = rotation @ p_camera + translation`**，旋转是相机到雷达，平移是模型相机光心在雷达坐标中的位置；不能把 1.5 的减平移约定直接套入。`noise_norm` 是相应投影模型中归一化观测的标准差。本次局部虚拟相机参数不是物理硬件光心/外参，单次核心中作为常量；另用训练段重采样做标定敏感性分析。

预测 `q_camera=rotation.T@(p_target-translation)`，观测模型为 `[q_x/q_z,q_y/q_z]`，使用解析雅可比做 EKF 更新。没有相机伪深度，也不把雷达估计深度复制成独立观测。非正/奇异预测光学深度单独记为几何拒绝；坏输入及无效协方差直接报错。核心沿用手写 Kalman 的 Joseph 协方差更新。

相机输入若来自人工目标框/点，应明确为 oracle 视觉条件，不能宣称是作者 MobileNet 检测输出；不能投影真值生成检测框、从真值初始化或据真值关联雷达候选。真值只能在核心之外评价。

## 公平的时间与过程噪声

两组分别为 `radar_only` 与 `radar_camera`，输出均从共同初始化时刻起按 100 Hz 生成，包含初始化样本。预测分区为这些固定 ticks 与两组共同的全部雷达/相机采集事件的并集；相机事件即使在雷达基线中停用，其时刻仍参与基线预测分割，保证两组使用完全相同的 F/Q 时间分区。统一采集时间重放不是到达延迟或实时发布实验。

过程 Q 沿用 1.5 离散常加速度模型 `sigma_a² G Gᵀ`，其中 `G=[dt²/2,dt]`，不是连续白噪声谱密度。它的统计含义依赖分区；增加相机事件密度也会改变共同分区和雷达基线 Q。因此只在同一共同分区内比较两组，不把不同事件密度实验视为完全同一过程噪声。2.0 的连续白加速度 Q 是另行研究路线，未悄悄替换到 1.6。

所有示例噪声和门槛都需在结果中记录，没有从论文或评估真值反推。实际精度结论还需校准、检测输入、参考点与时钟确证。
