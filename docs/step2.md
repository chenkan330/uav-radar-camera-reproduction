# 第 2 步：雷达点云初始化、门控与数据关联

本步把第 1 步的单个三维雷达位置观测扩展为真实雷达可提供的五字段点云接口，并实现论文的五种关联方案。实验输入仍为固定随机种子的合成点云，含目标回波、杂波、初始化静止阶段和空帧。本步验证数学与处理流程，不复现论文的真实飞行精度。

## 本步干了什么

- 新增 `radar.py`：校验 Nx5 `[x,y,z,vx,intensity]`，对应论文式 (9)；位置单位米、vx 单位米/秒。
- 按论文 IV-A，比较连续两帧各自最强点的位置距离/时间，严格小于 0.3 m/s 才初始化；初始化前不门控。空帧中断连续配对。
- 雷达观测矩阵提取状态 `[x,vx,y,vy,z,vz]` 的 `[x,y,z,vx]`，对应式 (10)。强度不进入观测向量。
- 所有关联方案先以 `S=H P Hᵀ+R` 计算四维 Mahalanobis 距离，过滤超门点，对应式 (16)。
- Strongest 选门内强度最大点；Closest 按门内 XYZ 欧氏距离选最近点；Average 求门内四维观测均值；K-means 按论文单簇设定直接取五字段均值，对应式 (17)–(20)。
- Weighted 按式 (21)–(26)实现完整 PDAF：合并创新、漏检概率项和创新离散度协方差。它不是把加权均值当成一个确定观测直接更新 Kalman。
- 空帧、空门只保留已有预测；未初始化时不会产生虚构状态。

## 论文未给出的数值与本实现假设

- 单点雷达噪声标准差 `[0.20,0.35,0.35,0.12]`，前三项米，最后项米/秒；`R` 为它们平方构成的对角阵。
- gate=3 表示 Mahalanobis **距离**阈值，不是平方距离阈值；不宣称是论文的门限。
- Weighted 的 `beta0=0.1` 是可配置演示参数。论文说明其含义，但没有给出确定它的检测概率/杂波模型或数值。门内 `beta_i=(1-beta0)*I_i/sum(I)`；要求非负线性强度及正总强度。dB SNR 不能直接当线性权重，程序也不会自动猜测其转换。
- 初始化使用第二帧最强点的 XYZ、测得 vx，设 vy/vz=0。观测四维的初始协方差为 R；vy/vz 标准差 2 m/s。初始化点只被消费一次。
- 采用第 1 步的过程加速度标准差 0.8 m/s²。平均/单簇关联沿用单点 R，不依据点数缩小 R，因为论文未保证回波独立。
- 为使初始化演示可重现，合成点云的头两帧目标位置噪声明确设置为 0.002 m。之后噪声、近邻杂波和空帧独立展示跟踪过程。这不代表真实雷达能够满足相同初始化条件。

## 运行与验证

在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe demo_step2.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_radar.py -v
```

输出 `output/step2/metrics.json` 记录全部假设、五种方案位置 RMSE、初始化时间、预测帧数及协方差检查；`simulation.csv` 保存逐帧真值与估计，`clouds.csv` 保存合成非空点云，空帧由 simulation.csv 的 point_count=0 表示；`overview.png` 展示轨迹和误差。可以通过 `--seed`、`--gate`、`--beta0` 更改实验参数。

测试包括四维门控、门控优先于选最强点、Closest 的三维距离含义、连续帧初始化与掉帧、空门状态不变、单簇均值、PDAF 手算矩、与独立显式高斯混合计算的等价性及协方差正定性。具体本机运行结果另由步骤提交附带的 metrics.json 保存。

## 接入真实数据还缺什么

需要雷达原始点云、每帧时间戳、坐标轴方向、单位、速度字段的物理含义和强度字段的定义。尤其不能未经确认将径向 Doppler 速度当作 vx，或将 dB SNR 当作线性权重。论文性能对比还需要同步真实轨迹真值；本步合成曲线与论文表格不具备可比较性。
