# 第 3 步：相机检测框与坐标转换

## 本步做了什么

1. 对应论文式 (11)：接收像素单位的检测框 `[xmin,ymin,xmax,ymax]`，取中心 `[u,v]`；置信度低于 0.70 的检测不用于观测。恰好 0.70 时保留。
2. 对应式 (12)–(14)：利用相机内参 `fu,fv,u0,v0` 和当前状态的 `x` 构造相机坐标 `[cx,cy,depth]`。深度必须为正，未初始化的跟踪器不能使用这条观测。
3. 对应式 (15)：实现相机到全局坐标的外参转换及逆投影，并支持调用者提供旋转和位移。
4. 单独提供二维像素 bearing 观测，避免将状态复制出的深度当成新的独立测量。这是对论文伪 XYZ 观测的数值改进，需在结果中明确标记。
5. 生成固定种子的合成检测框，演示置信度过滤、投影与回投影、一次像素观测修正，保存 CSV、参数与指标、示意图。

## 论文公式与实现约定

论文式 (15) 写为**行向量**：`global = camera @ M - translation`，其中

```text
M = [[0,-1,0], [0,0,-1], [1,0,0]]
```

本项目使用列向量，因此 `global = M.T @ camera - translation`。相机坐标 `[1,2,10]` 在零位移情况下对应全局 `[10,-1,-2]`；全局 X 是前向深度，Y/Z 与相机图像横向/纵向的符号相反。自定义外参仍使用同一位移符号，不可直接把其他工具中的相机位置作为 `translation` 而不检查其约定。

`camera_project` 用 `camera = rotation.T @ (global + translation)` 做逆变换，再计算针孔投影。示例不含镜头畸变；实际检测框应先使用真实相机标定结果去畸变，或者增加对应模型。自定义旋转可包含测得的安装姿态/IMU 姿态，但本步没有标定真实硬件。

## 为什么提供两种观测

`paper_pseudo_observation` 默认严格使用 `depth_source="paper_state_x"`，即论文中的 `X(0,0)`。它返回三维 XYZ 及协方差，`depth_std` 为可配置的深度标准差，像素和深度的误差通过回投影雅可比传播。使用非零外参或倾斜相机时，可明确选择 `depth_source="camera_forward"`，使用当前状态转换后的相机前向深度；该选择偏离论文的字面公式。

这些 XYZ 的深度来自当前状态，因而与当前状态相关。把它们直接作为独立三维 Kalman 测量会重复计算已有深度信息、缩小不确定度；调整 `depth_std` 不能消除这个相关性。`uses_state_as_depth=True` 标出这一限制。本步示例保存伪 XYZ 供核对公式，滤波修正使用二维 bearing 模式。

`camera_bearing_observation` 对针孔模型 `h(state)=[u,v]` 在当前状态处线性化，返回 `H=dh/dstate`、`z=pixels-h(state)+H@state`、`R=diag(pixel_std²)`，可直接调用 `Kalman3D.update_linear(z,R,H)`。因此创新就是实际像素减预测像素。它只提供两行角度约束，没有独立的深度行；轴线上、无轴间先验相关性时，不会减少深度方差。离轴观测仍可通过角度几何关系或先验相关性修正深度，这是 bearing 观测的正常作用。

线性化假定当前估计足够靠近目标；极大的初始误差、接近零深度、严重标定误差均不在此简单模型的适用范围。每次相机更新前必须重新在当前状态处构造观测，不能复用旧雅可比。

## 运行与输出

```powershell
.\.venv\Scripts\python.exe demo_step3.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_camera.py -v
```

默认输出 `output/step3/camera_observations.csv`、`metrics.json`、`camera_observations.png`。示例使用 VGA 图像、`fu=fv=420 px`、图像中心 `[320,240]`、零位移、2 px 噪声、seed 42、201 帧；全部是**合成示例参数**，不是论文公开的真实内参、外参或观测数据。每一帧从独立的合成先验开始，仅验证一次相机修正；连续的异步跟踪在第 4 步实现。

测试核对轴向与位移符号、带旋转的投影往返、置信度边界、有限差分像素雅可比、中心射线不创造深度信息、伪 XYZ 协方差、无效深度/参数。运行结果中的误差只适用于该合成案例，不用于声称论文实测精度。

2026-10-06 本地运行：7 项相机测试全部通过；默认示例接受 178/201 个检测框，投影往返最大绝对误差 `6.66e-16 m`，横向位置 RMSE 从 `0.4913 m` 降至 `0.1985 m`。图已生成并检查标题、坐标与图例显示。
