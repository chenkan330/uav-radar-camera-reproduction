# m³TrackFormer 多目标实验

V6 匿名身份关联基准见 `versions/v6_20261117_074248_895531_test_v5_gate_review/`。后续实验及已发布材料见下表。

本项目使用雷达距离/角度测量与Transformer进行波束跟踪。原始GNSS是参考轨迹，雷达测量、SNR及异常值为仿真。通常3个初始化目标共享12束，每段评估49.8秒；不同版本的场景及指标定义以各自summary和报告为准。

V1为初始多目标，V2为扰动未优化，V3为Huber预处理。早期独立运动概率V4仅作历史探索；后续主线保留原N-Net/R-Net结构与固定权重。V5是未反馈关联结果的条件身份审计；V6才把匿名关联实际送入Huber及原N/R历史，正确身份与可用更新分别评价。

V6身份有效成功率采用任一初始身份连续5帧无正确关联即失跟的事后判据；真值不决定在线停止。原N/R的Softmax求和Top-12规则保持，R-Net只接受确认无回波的波束负证据。

当前Huber主线蓝线为原N-Net的位置头输出。物理漏检重捕与含拒配的更新恢复分别报告，不能混用。17组场景的3组噪声重复不是51个独立真实场景；既有测试记录不是新盲测。RMSE需结合评价覆盖率理解。

源码和结果可直接查看。重跑需自行准备对应数据、权重与本地实验指针配置；详细入口见my_training/README.txt。原始数据集、模型权重、逐帧测量/轨迹CSV、本机路径配置及缓存不在公开范围。
