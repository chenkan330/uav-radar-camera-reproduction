# DFT 波束训练惩罚对齐与 OTFS 闭环复测

训练标签使用半格中心的 32 × 32 DFT 方向余弦网格。旧损失把同一类别编号解释为 64 × 16 的方位角和俯仰角网格。修正后从标签所用的同一码本读取中心坐标，用候选波束与正确波束的平方方向余弦距离计算加权惩罚。

在相同的 17 组三目标、CP-OTFS 单径仿真场景上，比较原模型和使用对齐损失重训的模型。两次回放使用相同阵列、波形、噪声种子、每帧 12 束预算和身份关联参数。

| 模型 | 三目标完整跟踪 | 平均同时跟踪时长 |
|---|---:|---:|
| 原模型 | 14/17 | 42.17 s |
| 统一 32 × 32 编号后重训 | 14/17 | 42.20 s |

时长变化来自一个场景延长 0.45 秒。修正解决了波束编号在训练标签与惩罚项之间的几何不一致。这组复测与预测 CSI 选束对照分别进行了评价。
